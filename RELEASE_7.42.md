# NEON VOID 7.42 — CHAOS BUILD

> Экспериментальный отдельный релиз. Ветка: `release/7.42`. В `master` эти изменения не попадут автоматически.

## Новые улучшения

- **Банановый турбо-режим** — +8% скорости движения за уровень.
- **Эспрессо из бездны** — скорострельность становится выше.
- **Налоговая броня** — дополнительный слой брони (общий предел брони сохраняется).
- **Пельменный корпус** — +1 к максимуму HP и немедленное лечение.
- **Критический Wi-Fi** — +8% шанса критического урона за уровень.

У всех пяти улучшений есть ограничения по уровням. Они работают в обычном цикле выбора улучшений и не требуют отдельного режима.

## Полировка

- Версия 7.42 видна в заголовке окна и на главном экране.
- Добавлены автоматические тесты на игровые эффекты и лимиты новых улучшений.
- Релиз публикуется с тегом `v7.42`, но не становится GitHub Latest, чтобы не подменять основной стабильный релиз.

## Сборка

Windows 10/11 x64. Запусти скачанный `NEON VOID.exe`.

## Изоляция

Этот релиз собран из ветки `release/7.42`. Он не объединён с `master`; основная ветка и её текущий релиз остаются отдельно.
