# NEON VOID v0.2.1

## Fixes
- Stabilized repeated F11 fullscreen/windowed switching.
- Added a fallback display mode for SDL drivers that reject SCALED.
- Prevented rapid duplicate fullscreen toggle events.
- Preserved the previous display state if a mode transition fails.

This release is built from the verified release branch and includes the current v0.2.1 website and documentation updates.
